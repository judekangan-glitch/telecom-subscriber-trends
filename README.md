# Telecom Subscriber Trends by Operator, 2022 to 2023

3MTT project DA-12, 2026. Built with Excel and Power BI.

## The question

How did subscriber numbers change across Nigeria's four mobile operators, MTN, Globacom, Airtel and 9mobile, between September 2022 and September 2023?

## Data

Nigerian Communications Commission (NCC), Quarterly Subscriber Operator Data, September 2022 to September 2023.

## What is in this repository

| Folder | Contents |
| --- | --- |
| `data/` | Workbook with the raw table as published, a long-format Master Data sheet with quarter-on-quarter change formulas, and a README sheet |
| `powerbi/` | Power BI file (`TelecomSubscriberTrends.pbix`) |
| `docs/` | One-page insight summary |
| `screenshots/` | Dashboard views: all operators, MTN, Globacom, Airtel, 9mobile |

## How I built it

1. Kept the raw NCC table exactly as published.
2. Rebuilt it in long format as an Excel Table with quarter-on-quarter change formulas.
3. Built a Power BI dashboard with an operator filter, KPI cards, a trend line, a ranked bar chart and a detail table.
4. Wrote a one-page insight summary.

## Main findings

- The four operators had about 221.3 million subscribers by September 2023: MTN about 38.8%, Globacom 27.8%, Airtel 27.2% and 9mobile 6.2%.
- MTN fell 7.5% between March and June 2023, then recovered 1.4% the next quarter, but was still below its March level.
- 9mobile is the smallest operator but grew fastest, about 7.2% over the year.
- Globacom grew in every quarter. Airtel was almost flat after December 2022, with one small dip of 0.2% in June 2023.
